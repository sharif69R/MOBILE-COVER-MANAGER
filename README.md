 # Mobile Cover Manager

Offline-first Android inventory app for mobile phone covers.

- Search the free TechAPI smartphone catalogue (internet required for new searches).
- Save model, cover quantity, and optional description.
- Local SQLite storage; saved inventory works offline. No Firebase or Supabase.
- Edit/delete stock entries.
- Attempts to find and cache a phone image using Wikimedia Commons when saving; exact matches are not guaranteed.

Catalogue: https://github.com/GetTechAPI/TechAPI (CC-BY-SA 4.0; curated, not exhaustive).

## Build APK
Open GitHub Actions and run Build Android APK. Download the mobile-cover-manager-apk artifact from the completed workflow run.
